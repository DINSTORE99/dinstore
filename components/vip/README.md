# VIP component

Komponen VIP dijalankan dari repository DINSTORE-VPN utama.

Dari root project:

```bash
chmod +x install.sh
sudo ./install.sh
```

Pilih `2` untuk VIP atau `3` untuk seluruh stack.

File internal VIP berada di `components/vip/` dan tidak perlu di-download ulang dari repository DINSTORE lain.
